معماری کامپیوترComputer Architecture

معماری کامپیوتر نشان می‌دهد پردازنده، حافظه و ورودی/خروجی چگونه کنار هم یک کامپیوتر کامل می‌سازند و دستورها چگونه اجرا می‌شوند.

۱معرفی درسIntroduction

بعد از اینکه این درس رو یاد بگیرید (یا حتی در فرایند یادگیریش)، اولین چیزی که متوجهش می‌شین اینه که کامپیوتر دیگه یک Magic Box یا «جعبه جادویی» نیست. اینکه چجوری کامپیوتر داره این همه کارهای عجیب‌وغریب می‌کنه، صرفاً می‌شه یه بخشی از دانش شما! (و خب دیگه اون‌قدرها هم عجیب به نظر نمیاد).

این درس روی دانش «مدار منطقی» شما سوار می‌شه و تقریباً همون چیزهایی رو که اونجا یاد گرفتید، حالا سعی می‌کنه همه رو کنار هم بذاره تا یه کامپیوتر بسازه.

  1. ۱

    کد سطح بالاHigh-Level Code

    برای اینکه ببینیم پردازنده چیه، با یه مثال توضیح می‌دم. فرض کنید یه همچین کدی داریم:

    C
    A = 2 + 3;
  2. ۲

    کامپایلرCompiler

    این کد یه توصیف سطح‌بالا هست و برای اینکه بتونیم روی پردازنده اجراش کنیم، اول باید با کامپایلر (Compiler) کامپایلش کنیم (اینجا نظریه زبان‌ها و ماشین‌ها بهتون ثابت می‌کنه که کاربرد داشته!).

  3. ۳

    زبان اسمبلیAssembly

    بعد از اینکه این کد کامپایل بشه، به ما یه فایل اسمبلی تحویل می‌ده (main.s). به زبان اسمبلی کامپیوتر پایه و ساده‌ای که مال خود کتاب هست (معماری کامپیوتر پایه آقای مانو)، کد این شکلی می‌شه:

    main.s
    ORG 100        / Start the program at memory address 100

LDA NUM1       / Load the value of NUM1 into the AC (Accumulator)
ADD NUM2       / Add the value of NUM2 to AC and store result in AC
STA A          / Store the value in AC into memory location A
HLT            / Halt the execution of the program

NUM1, DEC 2    / Define NUM1 with decimal value 2
NUM2, DEC 3    / Define NUM2 with decimal value 3
A,    DEC 0    / Define A with initial value 0 (to store the result)
END            / End of the program

    توضیح هر خط رو جلوش نوشتم؛ خلاصه‌اش می‌شه اینکه:

    1. اول اون عددهایی رو که لازم داره گذاشته تو یه سری خونه از حافظه با آدرس‌های مشخص.
    2. بعد ۲ رو می‌ذاره داخل رجیستری به نام AC.
    3. بعد ۳ رو بهش اضافه می‌کنه و نتیجه رو دوباره می‌ذاره داخل AC.
    4. در نهایت مقدار رجیستر AC رو داخل خونه‌ای که ما صداش می‌کنیم A ذخیره می‌کنه!

    اینکه چجوری به زبان اسمبلی کد بزنید رو یه کم تو این درس و به‌صورت تخصصی‌تر داخل درس ریزپردازنده و اسمبلی یاد می‌گیرید.

  4. ۴

    اسمبلر و زبان ماشینAssembler & Machine Code

    حالا بازم شد یه مشت دستور که پردازنده مستقیماً درکی از متنش نداره؛ اینجا اسمبلر (Assembler) وارد می‌شه تا جای این دستورات، کدشون رو (که می‌شه یه مشت ۰ و ۱) بذاره. خروجیش می‌شه یه آبجکت فایل (main.o) که زبان ماشین هم صداش می‌کنن. می‌شه یه همچین چیزی:

    main.o
    0001000001101000
0010000001101001
0011000001101010
1111000000000000
0000000000000010
0000000000000011
0000000000000000

    هر چقدر برای ما ناخواناتر، برای کامپیوتر خواناتر!

  5. ۵

    اجرا روی پردازندهExecution on the CPU

    خوب حالا یه مشت صفر و یک داریم که باید از روی دیسک برن روی RAM و بعد دستور به دستور توسط پردازنده اجرا بشن.

    البته این مواردی که گفتم تا حدی به دروس دیگه‌ای مثل کامپایلر هم مربوط می‌شه، ولی به نظرم دید خوبی می‌ده که CPU قراره با چه چیزهایی سر و کله بزنه.

    پردازنده تشکیل شده از ۳ بخش اصلی:

    ALU
    واحد حساب و منطق (ALU)

    جایی که می‌خواید ۲ + ۳ رو حساب کنید (همون Binary Adder و Multiplexer و… خودمون در مدار منطقی).

    REG
    رجیسترها (Registers)

    همون‌طور که دیدیم موقع حساب و کتاب از رجیسترها استفاده می‌کنیم (دلیل اصلیش هم سرعت خیلی پایین‌ترِ RAM نسبت به CPU هست).

    CU
    واحد کنترل (Control Unit)

    بالاخره یه جوری باید به سیستم بگیم کِی جمع کنه و کِی نتیجه رو بذاره تو رجیستر.

    با همین بخش‌ها قراره همون صفر و یک‌ها اجرا بشن.

    تلاشمو کردم یه Big Picture بهتون بدم (که البته خیلی هم Big نبود!).

    پیاده‌سازی پردازندهBuild the Processor

    شما دو نوع کنترلر و ساختار کامپیوتر تو این درس می‌خونید: یکی سخت‌افزاری (Hardwired) و اون یکی ریزبرنامه‌نویسی‌شده (Micro-programmed). بعد از اینکه هر کدوم رو یاد گرفتید، داخل نرم‌افزار Logisim واسه خودتون پیاده‌سازیش کنید؛ هم فانه، هم فوق‌العاده آموزنده! پیاده‌سازیشون با Verilog هم می‌تونه یک تمرین ساده و جذاب باشه.

    Logisimپیاده‌سازی گرافیکی مدارها
    Verilogپیاده‌سازی با زبان توصیف سخت‌افزار

    شبیه‌ساز اسمبلی مانوMano Assembly Simulator
