سیستم‌عاملOperating Systems

سیستم‌عامل واسطه‌ی میان سخت‌افزار و برنامه‌هاست؛ در این درس یاد می‌گیرید منابعی مثل پردازنده و حافظه چگونه مدیریت و میان برنامه‌ها تقسیم می‌شوند.

۱معرفی درسIntroduction

فرض کنید یه تعدادی سخت‌افزار یا Resource دارید. یک نرم‌افزار می‌تونه یک برنامه ساده باشه که خودتون نوشتید یا یک چیزی در ابعاد Photoshop. از معماری می‌دونیم که برای اجرای این برنامه‌ها، باید برن داخل حافظه اصلی (RAM) و از اونجا برن داخل CPU اجرا بشن.

خوب، حالا این کارهایی که گفتیم رو کی انجام می‌ده؟ کی Resource های ما رو مدیریت می‌کنه و تصمیم می‌گیره هر برنامه چقدر از حافظه اصلی رو بگیره یا چه مدت از CPU استفاده کنه؟ تو این درس قراره جواب این سوالات رو بگیرید.

۲منابع یادگیریLearning Resources

  1. ۱

    دوره‌ی ویدیوییVideo Course

    برای این درس، دوست‌داشتنی‌ترین دوره، دوره دکتر ابریشمی از دانشگاه فردوسی مشهد هست؛ اگر نبینید ضرر کردید. برای اینکه متوجه قشنگی این دوره بشید، کافیه از یکی از سال‌بالایی هاتون راجع‌بهش بپرسید. راجع به اهمیت درس هم خیلی می‌شه صحبت کرد؛ همین‌قدر بگم که بیشتر جای‌خالی‌هایی رو که داخل ذهنتون هست و معماری پر نکرده، سیستم‌عامل قراره پر کنه. این یکی از درس‌هایی هست که بعداً از خودتون بابت یادگرفتنش تشکر می‌کنید.

    دوره‌ی دکتر ابریشمیلینک درس در OCW دانشگاه فردوسی مشهد
  2. ۲

    کتاب سیلبرشاتزSilberschatz Textbook

    کتاب‌هایی هم که می‌تونید بخونید، کتاب‌های آقای سیلبرشاتز (Silberschatz) و تننباوم (Tanenbaum) هستند. برای شروع، بهتره که با کتاب سیلبرشاتز شروع کنید. انتهای کتاب چند بخش تحت این عناوین می‌بینید:

    Summary

    می‌تونید ازش به عنوان یک Knowledge Check استفاده کنید؛ به این صورت که بعد از یک تایمی که درس رو خوندید، این موارد رو دوباره بخونید و باهاش چک کنید چه مواردی رو فراموش کردید.

    Practice Exercises

    اینجا یه سری سوال به اصطلاح تئوری و حل‌کردنی می‌بینید. برای شروع و آشنایی با درس خوبه، ولی احتمالاً بیشتر از این‌ها به سوالات حل‌کردنی نیاز خواهید داشت.

    Programming Problems

    به‌شدت سوالات جذابی اینجا می‌بینید، فقط باید سعی کنید خیلی سمت LLMها نرید و اول یک پلی‌لیست از System Programming داخل یوتیوب ببینید و بعد برید سراغ حل سوالات.

    کتاب سیلبرشاتزSilberschatz · نقطه‌ی شروع
  3. ۳

    پلی‌لیست‌های پیشنهادیSuggested Playlists

    این پلی‌لیست‌ها برای System Programming هستند؛ مباحث Process ها و Thread ها (از دید برنامه‌نویسی).

    پلی‌لیست اولپلی‌لیست یوتیوب · System Programming (Processes & Threads)پلی‌لیست دومپلی‌لیست یوتیوب · System Programming (Processes & Threads)

    پروژه‌ی پیشنهادیSuggested Project

    Kernel خودتون رو بزنید! می‌تونید کلیدواژه‌هایی مثل Building OS و Building Kernel رو سرچ کنید، یک پلی‌لیست از یوتیوب ببینید، یا این دوره از Udemy که داخل سایت Git.ir قرار داده شده رو ببینید:

    Developing a Multithreaded Kernel from Scratchدوره‌ی Udemy · Git.ir
  5. ۵

    تمرین بیشتر: SemaphoreهاMore Practice: Semaphores

    اگر دوست داشتید از Semaphoreها بیشتر سوال حل کنید، پیشنهاد می‌کنم حتماً به کتاب Little Book of Semaphores یه نگاهی بندازید.

    Little Book of Semaphoresکتاب تمرین
  6. ۶

    کتاب تننباومTanenbaum Textbook

    بعد می‌تونید برید سراغ کتاب تننباوم؛ این کتاب نسبت به کتاب آقای سیلبرشاتز می‌شه گفت Realisticتره. معمولاً پیشنهاد می‌کنند که اگر می‌خواهید کتاب تننباوم رو بخونید، مستقیماً برید سراغ کتاب آقای دکتر حقیقت که یک ترکیبی از کتاب‌ها با تمرکز بر کتاب آقای تننباوم هست.

    کتاب تننباومTanenbaum · مرجع Realistic
    کتاب دکتر حقیقتترکیبی با تمرکز بر تننباوم
